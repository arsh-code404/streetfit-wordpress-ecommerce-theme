# 🛍️ STREET.FIT – Custom WordPress eCommerce Theme

A modern streetwear-inspired eCommerce UI built using WordPress, WooCommerce, and custom theme development.

## 🚀 Features
- Custom WordPress Theme (No builder)
- WooCommerce Integration
- Mobile-first responsive design
- Hero section with overlay text
- Smooth scroll navigation
- Product grid with dynamic pricing
- Sale badge & ratings UI
- Clean and modern streetwear aesthetic

## 🧱 Tech Stack
- PHP (WordPress Theme Development)
- HTML5 & CSS3
- WooCommerce
- Advanced Custom Fields (ACF)

## 📱 Responsive Design
Optimized for:
- Mobile devices (primary focus)
- Tablet & desktop

## 📸 Key Sections
- Hero Banner with CTA
- Brand showcase
- New Arrivals product slider/grid

## ⚙️ Setup Instructions
1. Clone the repo
2. Place theme in `/wp-content/themes/`
3. Activate theme in WordPress
4. Install WooCommerce & ACF plugins
5. Add products under "New Arrivals" category
